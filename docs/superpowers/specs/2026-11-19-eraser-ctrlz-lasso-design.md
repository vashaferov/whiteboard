# Ластик для всех объектов, Ctrl+Z и лассо: дизайн

**Дата:** 2026-11-19
**Статус:** решения согласованы с пользователем, дизайн на утверждении

## Зачем

1. Ластик сейчас удаляет только штрихи кисти — нужен для любых элементов.
2. `Ctrl+Z` не срабатывает на русской раскладке: обработчик сравнивает `event.key`
   с `z`, а приходит `я`. Нужно сочетание по физической клавише.
3. Нужен инструмент «Лассо»: рамкой выбрать несколько элементов и удалить или
   переместить их группой.

## Решения пользователя

- Ластик подчиняется обычным правам удаления: ученик — только свои
  незаблокированные, staff — любые незаблокированные; замок защищает всех.
- Фрейм стирается только при касании границы; внутри фрейма стирается содержимое,
  сам фрейм остаётся.
- Лассо выбирает только объекты, доступные пользователю для правки.

## 1. `Ctrl+Z`

- Сочетание определяется по `event.code === 'KeyZ'` (и `Meta+KeyZ` на macOS),
  поэтому работает в любой раскладке. `Shift+Ctrl+Z` не отменяет.
- В полях ввода, `textarea`, `select` и редакторе текста сочетание не
  перехватывается (редактор сам гасит событие).
- Поведение отмены не меняется: текущая страница, staff на презентации,
  пустая история — тост «Нечего отменять».

## 2. Ластик

- `Board.eraseAt(point, radius)` обходит все объекты страницы, а не только штрихи:
  - штрих — по расстоянию до точек (как сейчас);
  - фрейм — только если точка у его границы (допуск радиуса);
  - остальные (фигуры, текст, картинки, стрелки, коннекторы) — по пересечению
    круга ластика с ограничивающим прямоугольником узла.
- Объекты, которые нельзя удалить (`deletePredicate`: автор/замок/роль),
  пропускаются; повторное наведение не дублирует удаление.
- Удаление идёт существующим `object_delete`: сервер сам убирает стрелки блока
  и проверяет права; у каждого объекта своя запись истории, поэтому `Ctrl+Z`
  возвращает их по одному.
- Фрейм при стирании границы удаляется вместе с содержимым — как кнопкой Delete.

## 3. Лассо

- Новый инструмент `data-tool="lasso"` в доке (иконка пунктирной рамки).
- Протяжка по пустому месту рисует пунктирный прямоугольник; по отпускании
  выбираются объекты, чьи границы пересекаются с рамкой.
- Выбираются только объекты, доступные для перемещения и удаления: группы
  (фигуры, текст, картинки, фреймы). Штрихи и коннекторы остаются для ластика и
  одиночного выбора — у них нет группового перемещения.
- Если выбран фрейм, его дети не добавляются в набор отдельно: они движутся и
  удаляются вместе с фреймом.
- Выделение показывается общим Transformer; клик по пустому месту или `Escape`
  снимает его. Одиночный клик по объекту инструментом лассо выбирает один объект.
- Перетаскивание любого выбранного объекта двигает всю группу; фреймы тянут
  своих детей, коннекторы перестраиваются.
- `Delete`/`Backspace` удаляет выбранное; если среди выбранного есть фрейм —
  одно подтверждение. Удаление и перемещение группы — **одна запись истории**,
  поэтому один `Ctrl+Z` возвращает всю группу.
- На презентации лассо скрыт/недоступен.

## Протокол для групповых действий

Чтобы группа отменялась одним `Ctrl+Z`, добавлены два сообщения:

- `objects_delete {objectIds}` — проверяет каждый объект (страница, права, замок),
  удаляет допустимые вместе с каскадом (стрелки, дети фрейма) и пишет одну
  запись истории; каждому клиенту уходят обычные `object_delete` события.
- `objects_move {updates: [{objectId, x, y}]}` — проверяет каждый объект,
  пишет одну запись полей `x/y/frameId`, обновляет позиции и рассылает обычные
  `object_update` события.

Ограничение списка — 200 объектов; пустой список игнорируется. Одиночные
`object_delete`/`object_update` остаются без изменений.

## Границы

- Новых зависимостей нет; протокол расширяется, формат снимков не меняется.
- Лассо не двигает штрихи/коннекторы; они доступны ластику и одиночному выбору.
- Ластик не удаляет заблокированное и чужое для ученика.
- Презентации: лассо недоступен, ластик доступен только staff и стирает пометки.

## Проверка

- Backend: групповое удаление/перемещение, права, замок, каскад, одна запись
  истории; обычные сообщения не регрессировали.
- E2E: `Ctrl+Z` с `key: 'я', code: 'KeyZ'`; ластик удаляет фигуру/текст/картинку,
  не удаляет фрейм изнутри, уважает замок; лассо выбирает рамкой, двигает группу,
  удаляет группу и отменяет одним `Ctrl+Z`; ученик не выбирает чужое.
- Полная регрессия: backend, `ruff`, `black`, Playwright, `docker compose config`.
