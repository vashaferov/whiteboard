# Разные шрифты для объектов «Текст»: дизайн

**Дата:** 2026-11-18
**Статус:** на утверждении
**Связанный пункт бэклога:** «Добавить возможность использовать разные шрифты для объекта "Текст"».

## Зачем

Сейчас весь текст на доске рисуется одним семейством (`Inter, "Segoe UI", Roboto, Arial`).
Учителю нужен выбор хотя бы между обычным, засечным, моноширинным, рукописным и узким
шрифтом — например, чтобы отделить заголовок от пометок или подчеркнуть цитату.
Выбор должен быть свойством самого объекта: синхронизироваться между участниками,
сохраняться в снимке, переживать перезагрузку и отменяться через историю.

## Границы

- **Только объекты типа `text`.** Подписи блок-схем, стрелки, фреймы и изображения
  не затрагиваются: у блоков шрифт остаётся прежним.
- Шрифты — **системные**, без загрузки из интернета: доска должна работать в школьной
  сети без внешних запросов. Набор из пяти семейств фиксирован в коде.
- Новых зависимостей нет, формат снимков/Redis не меняется (поле просто добавляется
  в объект, как `fontSize`).
- Размер и цвет текста работают как раньше; размер по-прежнему выводится из толщины.

## Выбранный подход

Рассматривались три варианта:

1. **Короткий ключ в объекте + белый список на сервере (выбран).**
   В объекте хранится `fontFamily: "sans" | "serif" | "mono" | "hand" | "narrow"`,
   сервер проверяет значение Pydantic-типом, клиент разворачивает ключ в CSS-стек.
   Стабильные снимки, нельзя прислать произвольный CSS, семейство легко добавить позже.
2. Хранить CSS-строку целиком — гибко, но в данных доски оказывается презентационный
   CSS, а сверка строк хрупкая.
3. Локальная настройка пользователя без поля в объекте — не выполняет задачу:
   шрифт не синхронизируется и не сохраняется на доске.

## Набор шрифтов

| Ключ | Подпись в UI | CSS-стек |
|---|---|---|
| `sans` | Обычный | `Inter, "Segoe UI", Roboto, Arial, sans-serif` |
| `serif` | С засечками | `Georgia, "Times New Roman", serif` |
| `mono` | Моноширинный | `Consolas, "Courier New", monospace` |
| `hand` | Рукописный | `"Segoe Script", "Comic Sans MS", cursive` |
| `narrow` | Узкий | `"Arial Narrow", "Liberation Sans Narrow", sans-serif` |

Отсутствие `fontFamily` у старых объектов означает `sans`.

## Протокол и сервер

- `TextAdd` получает поле `fontFamily: Literal[...] = "sans"` — старые клиенты
  продолжают работать.
- Новое сообщение `TextFont` (`type: "text_font"`, `objectId`, `fontFamily`) меняет
  только шрифт, не пересылая содержимое. Неизвестный шрифт отклоняется валидацией
  как `invalid_message`.
- Обработчик `_handle_text_font` повторяет правила прав текста: объект существует
  в текущей странице, это `text`, автор или staff; для ученика — ещё и не заблокирован.
  Перед изменением в историю пишется `_push_fields(..., ("fontFamily",))`, чтобы отмена
  вернула прежний шрифт. Изменение рассылается остальным участникам страницы.
- На презентации сообщение автоматически отклоняется (`presentation_view_only`),
  потому что его нет в `PRESENTATION_ALLOWED`; текст на слайдах и так запрещён.
- Снимки и Redis ничего не меняют: `fontFamily` — обычное поле объекта.

## Клиент

- В панели инструментов появляется `<select id="font-select">` с пятью подписями.
  Он виден, когда активен инструмент «Текст», или когда выделен текстовый объект;
  на презентации и для чужого/заблокированного текста — скрыт или недоступен.
- Выбор в списке задаёт шрифт нового текста и сразу применяет его к выделенному
  объекту (локально + `text_font`). Для нового текста значение живёт в состоянии
  клиента до перезагрузки; в `localStorage` не пишется.
- `Board._createTextNode` берёт стек по ключу; редактор текста (overlay) показывает
  тот же шрифт; PDF-экспорт рисует Konva-сцену и получает шрифт автоматически.
- При выборе объекта `updateFontControl` синхронизирует список с его шрифтом.
- Входящее `text_font` обновляет данные объекта и Konva-узел без пересоздания.

## Отмена и права

- Отмена изменения шрифта возвращает предыдущее значение через общую историю полей.
- Ученик может менять шрифт только у своего незаблокированного текста; учитель
  и администратор — у любого текста, включая заблокированный (замок защищает
  только от учеников).

## Проверка

- Backend: создание текста с `fontFamily`, смена шрифта и broadcast, запрет
  ученику чужого текста, запрет на замке, невалидный ключ, отмена шрифта,
  `presentation_view_only`, сохранение поля в снимке.
- E2E: создать текст, выбрать «С засечками», увидеть шрифт в Konva; сменить
  у выделенного на «Моноширинный»; перезагрузить комнату — шрифт сохранился;
  ученик видит тот же шрифт и не может менять чужой; у блока шрифт не меняется.
- Регрессия: backend-набор, `ruff`, `black`, полный Playwright, `docker compose config`.

## Мои решения, которые стоит проверить

- Пять семейств и их ключи (`sans`, `serif`, `mono`, `hand`, `narrow`).
- Выбор шрифта не запоминается в браузере между сессиями.
- Отдельной кнопки/панели шрифтов нет — только выпадающий список в тулбаре.
- Блоки схемы остаются с прежним шрифтом.
