# Макет экрана комнаты — «Студия» (вариант A)

Интерактивный макет доски, без сборки и зависимостей.

## Открыть

Откройте `index.html` в браузере. Если браузер ограничивает локальные скрипты:

```bash
python -m http.server 8080
```

и откройте <http://127.0.0.1:8080>.

## Что посмотреть

- **Демо** в правом верхнем углу: роль «Учитель / Ученик / Админ» и режим
  презентации. Это часть макета, а не продукта.
- **Верхняя панель**: название комнаты, роль, текущая страница/слайд, статус,
  участники, «Ещё» и выход.
- **Док инструментов**: группы «Выбор», «Рисование», «Фигуры», «Схемы»,
  «Фрейм/текст», «Вставка»; палитра и толщина — в поповере по кнопке стиля.
- **Страницы**: активная страница, меню `⋯` с переименованием и удалением,
  добавление страницы, загрузка презентации (staff).
- **Участники**: роли, «Вы», чекбоксы и «К себе» (staff), «Всех к себе»,
  скрытые горячие клавиши, глаз невидимости у администратора.
- **Презентация**: слайд, счётчик, листание у учителя и режим просмотра у ученика.
- **Мобильный режим**: нижний док, выдвижные «Страницы» и «Участники»,
  лист инструментов, 44 px цели, без горизонтального скролла.

Скриншоты состояний — в `screens/`. Старый экран для сравнения — в `current/`.

## Файлы

- `index.html` — каркас, панели и доска (SVG-содержимое урока и слайда).
- `styles.css` — токены, компоненты, адаптив.
- `app.js` — демо-данные и интерактив.
