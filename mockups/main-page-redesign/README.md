# Макет главной страницы — вариант A «Кабинет»

Статичный интерактивный макет, без сборки и зависимостей.

## Открыть

Откройте `index.html` в браузере. Если браузер ограничивает локальные скрипты,
запустите из папки с макетом:

```bash
python -m http.server 8080
```

и откройте <http://127.0.0.1:8080>.

## Что посмотреть

- Переключатель ролей: в боковой панели на десктопе, в шапке на мобильном.
  Это часть макета, а не продукта.
- Ученик: только свои комнаты и кнопка «Войти в комнату».
- Учитель: создание комнаты, доступ, переименование и удаление.
- Администратор: все комнаты и отдельная страница пользователей с заявками.
- Поиск по комнатам, фильтры пользователей, диалоги и подтверждение удаления.
- Адаптив: 3 → 2 → 1 колонка, верхняя навигация на узких экранах.

Скриншоты состояний — в `screens/`.

## Файлы

- `index.html` — разметка и диалоги.
- `styles.css` — токены, компоненты, адаптив.
- `app.js` — демо-данные и интерактив.
